# Contributing

Mathematical criticism is the primary contribution sought by this release.
Please use the mathematical-review issue form and follow `REVIEWING.md`.

For a textual or code correction, open a pull request that:

- identifies the release and issue it addresses;
- keeps proof claims separate from exploratory numerical claims;
- preserves the explicit non-peer-reviewed status until a documented human
  review is received;
- updates the changelog and relevant checks when behaviour or claims change.

By contributing, you agree that your contribution may be distributed under the
licence applying to the modified file.
